# Formül özeti

## Birimler

$1\ \text{kW} = 860\ \text{kcal/h}$ · $1\ \text{W} = 3{,}6\ \text{kJ/h}$ · $1\ \text{mmSS} \approx 9{,}81\ \text{Pa}$

## Yalıtım ve ısı kaybı

| | |
|---|---|
| Isıl geçirgenlik | $\dfrac{1}{U} = R_{si} + \sum\dfrac{d}{\lambda} + R_{se}$ ($R_{si} = 0{,}13$, $R_{se} = 0{,}04$ duvar) |
| Özgül ısı kaybı (TS 825) | $H = H_T + H_V$ |
| İletim | $H_T = U_DA_D + U_PA_P + U_KA_K + 0{,}8U_TA_T + 0{,}5U_tA_t + \sum lU_l$ |
| Havalandırma | $H_V = 0{,}33\,n_hV_h$ |
| İç kazanç (konut) | $\Phi_i = 5\,A_n$ W, $\;A_n = 0{,}32\,V_{brüt}$ |
| Güneş kazancı | $\Phi_s = \sum r\,g\,I\,A$ |
| Aylık ısıtma ihtiyacı | $Q = [H(\theta_i - \theta_e) - \eta(\Phi_i + \Phi_s)]\,t$ |

## Isı kaybı cetveli (TS 2164)

| | |
|---|---|
| İletim kaybı | $Q_0 = \sum AU\Delta T$ |
| Artırımlı | $Q_T = Q_0(1 + Z_D + Z_W + Z_H)$ |
| Yön artırımı | K, KD, KB +5 %; G, GD, GB −5 %; D, B 0 |
| Sızıntı kaybı | $Q_s = \dfrac{1}{3{,}6}\sum(al)RH\Delta TZ_e$ |
| Toplam | $Q = Q_T + Q_s$ |

## Kazan, yakıt, depo

| | |
|---|---|
| Kazan kapasitesi | $Q_K = Q_h(1 + Z_R)$ |
| Kazan verimi | $\eta = \dot Q_K/(\dot m_{yakıt}H_u)$ |
| Saatlik yakıt | $B = Q_K/(H_u\eta)$ |
| Alt ısıl değerler | Doğal gaz ≈ 34 535 kJ/m³, fuel-oil ≈ 41 860 kJ/kg |
| Genleşme hacmi | $V_g = V_{sistem}\,n$ (90 °C için $n \approx 0{,}035$) |
| Kapalı genleşme deposu | $V = V_g\dfrac{P_{son} + 1}{P_{son} - P_{ön}}$ |
| Baca çekişi | $\Delta P = gH(\rho_{dış} - \rho_{gaz})$ |
| Yırtılma yüzeyi şartı | Tek kazan > 140 kW veya toplam > 1400 kW veya > 1100 W/m³ |

## Isıtıcılar ve sıcak su

| | |
|---|---|
| Radyatör gücü düzeltmesi | $Q = Q_n(\Delta T/\Delta T_n)^{1{,}3}$ |
| Su debisi | $\dot m = Q/(c\,\Delta T_{su})$ (90/70 sistemde $\Delta T_{su} = 20$ K) |
| Boyler gücü | $Q = \dot mc(T_s - T_{soğuk})$ |
| Lejyonella önlemi | Periyodik 65 °C |
