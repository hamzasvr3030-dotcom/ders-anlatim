# Formül özeti

## Temel

| | |
|---|---|
| Yoğunluk, özgül hacim | $\rho = m/V$, $\;v = 1/\rho$ |
| Sıcaklık | $T(\text{K}) = T(°\text{C}) + 273{,}15$ |
| Basınç | $P_{etkin} = P_{mut} - P_{atm}$, $\;P_{vak} = P_{atm} - P_{mut}$ |
| Hidrostatik | $\Delta P = \rho g\Delta z$ |
| Barometre | $P_{atm} = \rho g h$ |

## Enerji ve iş

| | |
|---|---|
| Toplam enerji | $E = U + \tfrac12 mV^2 + mgz$ |
| Mekanik enerji (akış) | $e_{mek} = P/\rho + V^2/2 + gz$ |
| Elektrik işi | $W_e = VI\Delta t$ |
| Mil işi / gücü | $W = 2\pi nT$, $\;\dot W = 2\pi\dot nT$ |
| Yay işi | $\tfrac12k(x_2^2 - x_1^2)$ |
| Birinci yasa | $E_g - E_ç = \Delta E$ |
| Çevrim | $Q_{net} = W_{net}$ |
| Verim | $\eta = $ istenen çıktı / gerekli girdi |

## Saf madde

| | |
|---|---|
| Entalpi | $h = u + Pv$ |
| Kuruluk | $x = m_g/m$ |
| Karışım özelliği | $y = y_f + xy_{fg}$, $\;x = (y - y_f)/y_{fg}$ |
| Sıkıştırılmış sıvı | $y \approx y_{f@T}$, $\;h \approx h_{f@T} + v_{f@T}(P - P_{doy})$ |

## Gazlar

| | |
|---|---|
| İdeal gaz | $Pv = RT$, $\;PV = mRT$, $\;R = R_u/M$ |
| İki hal | $P_1V_1/T_1 = P_2V_2/T_2$ |
| Sıkıştırılabilme | $Z = Pv/(RT)$ |
| İndirgenmiş | $P_R = P/P_{kr}$, $\;T_R = T/T_{kr}$ |

## Sınır işi

| Süreç | $W_s$ |
|---|---|
| $V$ sabit | 0 |
| $P$ sabit | $P(V_2 - V_1)$ |
| İzotermal ideal gaz | $P_1V_1\ln(V_2/V_1)$ |
| Politropik $n \ne 1$ | $\dfrac{P_2V_2 - P_1V_1}{1-n} = \dfrac{mR(T_2-T_1)}{1-n}$ |
| Doğrusal yay | $\dfrac{P_1+P_2}{2}(V_2 - V_1)$ |

## Kapalı sistem ve özgül ısılar

| | |
|---|---|
| Enerji dengesi | $Q - W = \Delta U + \Delta KE + \Delta PE$ |
| Sabit basınç | $Q - W_{diğer} = m(h_2 - h_1)$ |
| İdeal gaz | $\Delta u = c_v\Delta T$, $\;\Delta h = c_p\Delta T$, $\;c_p = c_v + R$, $\;k = c_p/c_v$ |
| Hava | $c_p = 1{,}005$, $\;c_v = 0{,}718$, $\;R = 0{,}287$ kJ/kg·K, $\;k = 1{,}4$ |
| Katı / sıvı | $\Delta u \approx c\Delta T$, $\;\Delta h = c\Delta T + v\Delta P$ |

## Kontrol hacmi

| | |
|---|---|
| Kütle debisi | $\dot m = \rho VA$ |
| Sürekli akış kütle | $\sum\dot m_g = \sum\dot m_ç$ |
| Akış işi | $Pv$ |
| Akan akışkan enerjisi | $\theta = h + V^2/2 + gz$ |
| Sürekli akış enerji | $\dot Q - \dot W = \dot m[\Delta h + \Delta V^2/2 + g\Delta z]$ |
| Lüle / difüzör | $h_1 + V_1^2/2 = h_2 + V_2^2/2$ |
| Türbin / kompresör | $\dot W = \dot m\lvert h_1 - h_2\rvert$ |
| Kısılma | $h_1 = h_2$ |
| Karışma | $\sum\dot m_g h_g = \sum\dot m_ç h_ç$ |
| Zamana bağlı | $Q - W + \sum m_gh_g - \sum m_çh_ç = m_2u_2 - m_1u_1$ |
