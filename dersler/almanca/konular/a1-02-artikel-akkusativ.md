# A1 · Artikeller, çoğul, Akkusativ ve olumsuzluk

## Belirli ve belirsiz artikeller (Nominativ)

| | Eril (maskulin) | Dişil (feminin) | Nötr (neutrum) | Çoğul |
|---|---|---|---|---|
| Belirli | **der** Mann | **die** Frau | **das** Kind | **die** Kinder |
| Belirsiz | **ein** Mann | **eine** Frau | **ein** Kind | – |
| Olumsuz | **kein** Mann | **keine** Frau | **kein** Kind | **keine** Kinder |

**Artikel tahmin ipuçları** (istisnaları var):

| Genellikle **der** | Genellikle **die** | Genellikle **das** |
|---|---|---|
| Erkekler, günler, aylar, mevsimler | Kadınlar, çoğu -e ile biten isimler | Küçültme -chen, -lein |
| -er (kişi): der Lehrer | -ung, -heit, -keit, -schaft | -um: das Museum |
| -ismus, -ling | -ion, -tät, -ik, -ie | Mastardan isimler: das Essen |

## Çoğul

Almancada çoğul kuralları çeşitlidir; isimle birlikte öğrenmek en iyisidir. Çoğulun artikeli **her zaman die**'dir.

| Ek | Örnek |
|---|---|
| -e | der Tag → die Tag**e** |
| ¨-e | der Stuhl → die St**ü**hl**e** |
| -er / ¨-er | das Kind → die Kind**er**, das Haus → die H**ä**us**er** |
| -(e)n | die Frau → die Frau**en**, die Lampe → die Lampe**n** |
| -s | das Auto → die Auto**s** |
| (ek yok) / ¨ | der Lehrer → die Lehrer, die Mutter → die M**ü**tter |

## Akkusativ (-i hâli, belirtili nesne)

Fiilin doğrudan etkilediği nesne. **Yalnızca eril artikel değişir:** der → **den**, ein → **einen**, kein → **keinen**.

| | Eril | Dişil | Nötr | Çoğul |
|---|---|---|---|---|
| Nominativ | der / ein | die / eine | das / ein | die |
| **Akkusativ** | **den / einen** | die / eine | das / ein | die |

- Ich habe **einen** Bruder. *(Bir erkek kardeşim var.)*
- Ich kaufe **den** Tisch. *(Masayı alıyorum.)*
- Sie trinkt **eine** Tasse Tee.
- **Es gibt** einen Park hier. *(Burada bir park var.)* — **es gibt** her zaman Akkusativ alır.

**Akkusativ zamirleri:** mich (beni), dich (seni), ihn (onu – eril), sie (onu – dişil), es, uns, euch, sie / Sie.

**Akkusativ alan edatlar:** **durch, für, gegen, ohne, um** (ayrıca bis, entlang)

- Das Geschenk ist **für dich**. · Ich gehe **ohne meinen** Bruder.

## Olumsuzluk: nicht mi, kein mi?

- **kein:** Belirsiz artikelli veya artikelsiz **isimleri** olumsuzlar.
  - Ich habe **kein** Auto. *(Arabam yok.)* · Das ist **keine** gute Idee. · Ich habe **keine** Zeit.
- **nicht:** Fiilleri, sıfatları, zarfları, belirli artikelli isimleri olumsuzlar.
  - Ich komme **nicht**. · Das ist **nicht** teuer. · Ich kenne den Mann **nicht**.

## İyelik sıfatları

| Zamir | İyelik | Örnek (Nom.) |
|---|---|---|
| ich | mein | **mein** Vater, **meine** Mutter |
| du | dein | **dein** Buch |
| er / es | sein | **sein** Auto |
| sie | ihr | **ihre** Tasche |
| wir | unser | **unser** Haus |
| ihr | euer | **eure** Lehrerin |
| sie / Sie | ihr / Ihr | **Ihr** Name |

İyelik sıfatları **ein** gibi çekilir: Ich sehe **meinen** Vater (Akk., eril).
