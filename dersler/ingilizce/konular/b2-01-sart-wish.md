# B2 · Üçüncü ve karma şart cümleleri, wish

## Third conditional (geçmişe dair hayal)

Geçmişte **olmamış** bir durumu ve onun **olmamış** sonucunu anlatır; pişmanlık ve eleştiri için kullanılır.

**If + had + V3, would have + V3**

- If I **had studied** harder, I **would have passed** the exam. *(Daha çok çalışsaydım geçerdim — çalışmadım, geçemedim.)*
- If we **had left** earlier, we **wouldn't have missed** the train.
- She **would have come** if you **had invited** her.

**could have / might have:** If you had asked me, I **could have helped** you.

## Mixed conditionals (karma)

**Geçmişteki koşul → şimdiki sonuç:**

**If + had + V3, would + fiil**

- If I **had taken** that job, I **would be** rich now. *(O işi alsaydım şimdi zengin olurdum.)*

**Şimdiki koşul → geçmişteki sonuç:**

**If + Past Simple, would have + V3**

- If I **were** more organised, I **wouldn't have forgotten** the meeting. *(Daha düzenli biri olsaydım, toplantıyı unutmazdım.)*

## Şart cümlelerinin özeti

| Tür | Zaman | Yapı | Gerçeklik |
|---|---|---|---|
| 0 | Her zaman | If + V1, V1 | Genel gerçek |
| 1 | Gelecek | If + V1, will + V1 | Gerçek olasılık |
| 2 | Şimdi / gelecek | If + V2, would + V1 | Hayali |
| 3 | Geçmiş | If + had V3, would have V3 | Gerçekleşmemiş geçmiş |

## if yerine kullanılan yapılar

- **unless** (= if not), **provided / providing that**, **as long as** (… şartıyla), **in case** (… ihtimaline karşı), **otherwise** (aksi hâlde)
- Take an umbrella **in case** it rains.
- You can borrow my car **as long as** you drive carefully.

**Devrik şart (resmî):** **Had** I known, I would have told you. *(= If I had known)* — **Should** you need help, call me. *(= If you should need)*

## wish / if only

| Ne hakkında? | Yapı | Örnek |
|---|---|---|
| **Şimdiki** durumdan şikâyet | wish + **Past Simple** | I **wish** I **had** more free time. *(Keşke daha çok boş vaktim olsa.)* |
| **Geçmişteki** pişmanlık | wish + **Past Perfect** | I **wish** I **hadn't said** that. *(Keşke onu söylemeseydim.)* |
| Başkasının davranışından rahatsızlık / değişim isteği | wish + **would** | I **wish** you **would** stop talking. *(Keşke konuşmayı kesseydin.)* |
| Yetenek | wish + **could** | I **wish** I **could** speak Japanese. |

**If only** daha güçlü bir duygu ifade eder: **If only** I **had listened** to you!

## It's time / would rather

- **It's (high) time** we **left**. *(Gitme vaktimiz geldi de geçiyor — Past Simple, anlamı şimdi.)*
- I**'d rather** stay at home. *(Evde kalmayı tercih ederim.)*
- I**'d rather** you **didn't** smoke here. *(Burada sigara içmemeni tercih ederim — başka kişi için Past Simple.)*
